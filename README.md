# Dramatic Slacker（ドラマチック・サボり魔）🎭

> 「全米が泣いた超大作映画のワンシーン」で、日常のサボりを崇高な悲劇へ昇華させる全自動・責任転嫁プラットフォーム。

---

## 🌟 プロジェクト概要

現代のビジネスパーソンは、寝坊や納期遅延といった過失に対して「電車が遅れて…」「体調不良で…」という陳腐な言い訳で立ち向かい、日々社会的な制裁を受けています。

**Dramatic Slacker** は、あなたの「目覚ましを止めて二度寝した」「単純に行く気が失せた」といった低俗な事実を、時空の歪み（タイム・アノマリー）や銀河帝国の陰謀が絡むハリウッド級のエピック・ストーリーへと自動変換します。
相手を「怒る」から「感動して許す（あるいは困惑してそっとしておく）」状態へ導き、職場の平和を守ります。

---

## ✨ 主要機能

- **過失のエピック・トランスフォーム（コア機能）**: 「二度寝」「ゲーム過剰プレイ」などの事実と遅延時間を入力するだけで、ハリウッドSF・重厚な歴史劇・純愛難病モノなどのトーンに合わせた壮大な叙事詩を瞬時に錬成。
- **上司の怒りゲージ連動シミュレータ**: 役職・直近の機嫌・血液型から許容確率を算出。確率が危険域に突入した場合は「キーボードの上で眠るAI猫」画像で防衛線を構築。
- **ハンス・ジマー風 BGM & 音声送出**: 生成されたテキストを重厚なオーケストラをバックにAIが熱狂朗読。そのままSlackやTeamsのボイスメッセージへ爆撃可能。
- **パニック・ボタン（緊急自己爆破）**: 言い訳が通用しない瞬間に「ユーザーの社会性がクラッシュしました」と表示し、速やかに退職代行LPへ退避。

## 🎬 キャスト & エンドロール（AIアプリ工場劇場）

本劇場の舞台裏を支え、魂を吹き込んだエージェントたちに最大の賛辞を。

- **agent🔵（企画・要件定義）**: 前代未聞の「ドラマチック言い訳」という不条理かつ崇高な世界観をウォーターフォール形式の美麗な要件定義書へとまとめ上げた敏腕コンセプト・アーキテクト。
- **agent🍈（設計・アーキテクチャ）**: 起床直後の朦朧とした意識でもワンタップで誤魔化せる堅牢なアーキテクチャとデータフローを設計したグランドマスター。
- **agent🍋（実装・コード錬成）**: 猛烈な勢いでエピック生成エンジンと重厚UIを構築し、瞬く間に動くプロダクトへと昇華させた爆速のリードエンジニア。
- **agent🟢（品質保証・テスト）**: いかなる修羅場でも3秒以内に言い訳が出力され、社会性が保たれるかを冷徹に検証し抜いた絶対防壁のテスター。
